# JustWrite

A calm, distraction-free place to write your book.

**Download JustWrite and read about it at <https://laowaidave.github.io/JustWrite/>.**

Every version's files are on the [releases page](https://github.com/laowaidave/JustWrite/releases).
Installed copies of JustWrite update themselves from `update-2.json` here, which is signed by
Six Kingdoms Publishing; JustWrite checks the signature and each download's checksum before installing.
